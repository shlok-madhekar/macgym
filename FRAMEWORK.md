# MacGym v3: framework, not a demo

Positioning: "MacGym is a robot-learning framework for Apple Silicon. Define a robot in ~15 lines of Python, train 4,096 copies of it on your Mac's GPU in about a minute, export the policy to CoreML." The live viewer is a tool of the framework (`macgym view`), and the hero demo is the PLAYGROUND: edit a robot's definition in code, press Run, watch thousands of copies learn.

Existing internals (keep working, reuse, don't rewrite physics): macgym/envs/physics2d.py has Capsule, Joint, Model (generic planar multibody, auto-generated Metal kernel), LocoEnv (auto-reset, metrics, render_state, start-relative dist). macgym/rl/ppo.py PPO. macgym/server.py websocket server (v2 messages per REDESIGN.md). web/ = v2 viewer (paper/ink design per REDESIGN.md).

## Public API (macgym/__init__.py exports) — ALL agents code against exactly this
```python
import macgym as mg

robot = mg.Robot("tripod")                     # planar robot builder
torso = robot.body("torso", start=(0, 1.0), end=(0.6, 1.0), radius=0.06, density=1000)  # capsule, returns Body handle
leg = robot.body("leg", start=(0.0, 1.0), end=(0.0, 0.5), radius=0.04)
robot.joint(torso, leg, at=(0.0, 1.0), limits=(-1.0, 1.0), motor=80, damping=0.1, stiffness=0.0)  # returns Joint handle; motor = gear (N·m at action 1)
robot.set_root(torso)      # body used for camera/position/distance (default: first body)

task = mg.Task(
    reward=lambda s: s.root.vx - 0.001 * s.action_sq,     # s is a batched State view (mx arrays, shape (N,))
    done=lambda s: s.root.y < 0.4,                         # optional termination
    episode_steps=1000,
)
env = mg.make(robot, task, num_envs=4096, seed=0)          # -> BatchedEnv (LocoEnv-compatible: reset/step/render_state, metrics)
result = mg.train(env, iters=200, hidden=(256, 256), on_iter=None, save="runs/tripod.npz")  # returns TrainResult(policy, history)
policy = mg.load_policy("runs/tripod.npz", env)            # Policy with .act(obs) and .export(...)
policy.export("tripod.onnx")      # ONNX (needs `onnx` pip; agent installs) 
policy.export("tripod.mlpackage") # CoreML (needs `coremltools`; best effort, skip gracefully if unavailable)
mg.view(env, policy=None, port=8765)  # launches server+viewer for a custom env (train live)
gym_env = mg.to_gymnasium(env)    # gymnasium.vector.VectorEnv wrapper (numpy in/out) for SB3/CleanRL users
mg.robots.walker(), mg.robots.cheetah(), mg.robots.hopper(), mg.robots.tripod(), mg.robots.worm()  # built-in (robot, task) pairs written WITH the public API
```
State view `s` (inside reward/done; all fields mx arrays (N,)): s.root.{x,y,vx,vy,angle,omega,height}, s.body("name").{x,y,vx,vy,angle,omega}, s.joint("name"|index).{q,qd}, s.action (N,A), s.action_sq (N,), s.contact("body_name") (0/1 ground contact), s.t (step index), s.dt. Observations are generated automatically from the robot (root height/angle/vels, joint q/qd, contacts) — user can override with `Task(obs=lambda s: ...)`.

## CLI (pyproject entry point `macgym`)
- `macgym train <file.py|builtin> [--envs 4096] [--iters 200] [--save path]` : file defines `robot` and `task` (or `def make_env(num_envs)`), prints a clean progress line with human units (distance m, steps/s).
- `macgym view [<file.py|builtin>]` : starts server + opens browser.
- `macgym bench` : runs scripts/bench.py.
- `macgym export <ckpt.npz> --format onnx|coreml`.
- `macgym new <name>` : scaffolds a robot file from a template.

## Playground (web/playground.html, served at /playground)
Left: code editor (CodeMirror 6 or Monaco via CDN, Python highlighting) with the robot file; preset dropdown (walker, cheetah, hopper, tripod, worm, "blank"). Right: live track (reuse v2 drawing code from web/app.js — factor shared canvas drawing into web/track.js) + small progress chart + generations. "Run" sends {"cmd":"run_code","code":...,"num_envs":4096} to the server; server execs the code in a sandboxed namespace (local dev tool; restrict builtins lightly; timeout on build), builds env via mg.make, starts training, streams v2 messages. Errors (syntax, invalid robot) returned as {"type":"error","message","line"} and shown inline in the editor. Robot preview: on code change (debounced), {"cmd":"preview_code"} returns a static render of the robot's rest pose to draw before training.
