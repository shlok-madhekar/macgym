Reference

Python API

The whole public surface of import macgym as mg. Robots and tasks are plain Python; everything after mg.make runs on the GPU.

import macgym as mg

Robot

mg.Robot(name="robot", friction=0.9, dt=0.02, substeps=8, iters=4)

Builder for a planar multibody robot. Bodies are capsules in the x/y plane, connected by hinge joints with a motor at each joint. dt is the control timestep (s), substeps physics substeps per control step, iters constraint iterations per substep, friction ground friction. Also: robot.validate(), robot.body_names, robot.joint_names, robot.body_index(name), robot.joint_index(name).

robot.body(name, start, end, radius=0.05, density=1000.0, color=None)

Adds a capsule. Returns a Body handle.

namestrUnique name, used by s.body(name) and s.contact(name).
start, endtuple[float, float]Endpoints of the capsule axis in metres, at rest pose.
radiusfloat = 0.05Capsule radius in metres.
densityfloat = 1000kg/m³. Mass and inertia are derived from the shape.
colorstr | NoneHex colour for the viewer; defaults to a palette.

robot.joint(parent, child, at, limits=(-1.0, 1.0), motor=50.0, damping=0.1, stiffness=0.0, name=None)

Connects two bodies with a hinge. Returns a JointHandle (.index is its action index). Each joint adds one action dimension.

parent, childBody | strHandles returned by robot.body, or body names.
attuple[float, float]Hinge location in world coordinates at rest pose.
limitstuple[float, float] = (-1.0, 1.0)Joint angle limits in radians, relative to rest; lo < hi.
motorfloat = 50.0Gear: torque in N·m at action = 1. Actions are clipped to [-1, 1].
dampingfloat = 0.1Viscous joint damping.
stiffnessfloat = 0.0Spring back toward the rest angle.
namestr | NoneDefaults to the child body name.

robot.set_root(body)

Selects the body used for s.root, the camera, and distance travelled. Defaults to the first body added.

Task

mg.Task(reward, done=None, episode_steps=1000, obs=None, name=None)

What the robot should learn. All callables receive a batched State. reward returns (N,) floats, done (N,) bools, obs (N, D). They run inside mx.compile, so use pure mx ops (no Python if on array values).

rewardCallable[[State], mx.array]Per-step reward.
doneCallable[[State], mx.array] | NoneTermination mask. Terminated robots auto-reset.
episode_stepsint = 1000Time limit in control steps.
obsCallable[[State], mx.array] | NoneOverride the automatic observation, mg.default_obs(s): root height, sin/cos of root tilt, root vx/vy/omega, joint q and qd, contact of every body.
namestr | NoneEnv name shown in logs; defaults to the robot name.

State

The batched view passed to reward, done and obs. Every field is an MLX array with one entry per robot.

FieldShapeMeaning
s.root.x, .y(N,)Root body centre in world metres (x is not reset-relative; distance is measured from the episode start internally).
s.root.vx, .vy(N,)Root linear velocity, m/s.
s.root.angle, .omega(N,)Rotation relative to the rest pose (rad, CCW positive) and angular velocity (rad/s).
s.root.height(N,)Alias of .y.
s.body("name" | i)(N,) eachSame fields as root, for any body: x y vx vy angle omega.
s.joint("name" | i)(N,) each.q angle and .qd velocity.
s.q, s.qd(N, J)All joint angles and velocities at once.
s.action(N, A)Actions applied this step, in [-1, 1].
s.action_sq(N,)Sum of squared actions. Handy for effort penalties.
s.contact("name")(N,)1.0 if the body's lowest point is within 2 cm of the ground, else 0.0. Name or index.
s.contacts(N, B)Contact flags for every body.
s.t, s.dt, s.num_envs(N,), float, intSteps into each episode, control timestep (s), batch size.

make

mg.make(robot, task=None, num_envs=4096, seed=0, backend=None) -> RobotEnv

Compiles the robot to a Metal kernel and allocates num_envs copies. The returned RobotEnv exposes reset() -> obs, step(actions) -> (obs, reward, done, info), obs_dim, act_dim, num_envs, dt, max_episode_steps, render_state(R), live_dist_mean() and running metrics, and auto-resets finished episodes. Also accepts the (robot, task) pair from mg.robots.* as one argument, or a legacy env name ("walker", "cheetah", "arm", "cartpole").

train

mg.train(env, iters=200, hidden=(256, 256), on_iter=None, save=None, lr=3e-4, seed=0, verbose=True, log_every=None, **ppo_kwargs) -> TrainResult

Runs PPO on the GPU. Returns TrainResult(policy, history, ppo): policy is a Policy, history a list of per-iteration metric dicts, ppo the underlying trainer; result.final is the last metrics dict. Extra keyword arguments go to the PPO constructor.

itersint = 200PPO iterations (rollout + update).
hiddentuple[int, ...]MLP hidden sizes for actor and critic.
on_iterCallable[[dict], bool | None] | NoneCalled after each iteration with the metrics dict (iter, dist, live_dist, mean_ep_return, mean_ep_len, ep_seconds, sps, env_steps, elapsed, ...). Return False to stop early.
savestr | NoneCheckpoint path (.npz) written at the end.
verbose, log_everybool = True, int | NonePrint a progress line every log_every iterations (default iters // 20).

evaluate

mg.evaluate(env, policy=None, steps=None) -> dict

Deterministic rollout from a fresh reset for steps control steps (default: episode length, capped at 500). Zero actions if policy is None. Returns {"dist", "return", "survived"}: mean root distance (m) before the first episode end, mean return, and the fraction that never terminated.

load_policy

mg.load_policy(path, env=None) -> Policy

Loads a .npz checkpoint. policy.act(obs) takes (N, obs_dim) or (obs_dim,), MLX or NumPy, and returns deterministic actions of the same kind in [-1, 1]. Also policy.save(path), policy.weights() (list of (W, b) NumPy arrays), obs_dim, act_dim, hidden, obs_mean, obs_var.

Policy.export

policy.export(path, format=None, verify=True, tol=1e-4) -> dict

Format is chosen from the extension (.onnx, .mlpackage, .npz) or format. With verify=True the exported model is run against the MLX actor and the result dict includes path and max_abs_err (None if the runtime is unavailable). .onnx needs onnx, .mlpackage needs coremltools. Install both with pip install -e ".[export]". CoreML export is best effort and raises a clear error if coremltools is missing.

view

mg.view(target=None, policy=None, port=8765, num_envs=4096, open_browser=True)

Starts the local server and opens the browser viewer, then blocks. target is a built-in name (trains live in the viewer), a path to a robot .py file (opens in the Playground and starts training), or None (pick a robot in the browser). It does not take an env object; for a custom robot, save it to a file and pass the path.

to_gymnasium

mg.to_gymnasium(env) -> MacGymVectorEnv (gymnasium.vector.VectorEnv)

NumPy in, NumPy out. Use with Stable-Baselines3, CleanRL, or your own trainer. Requires the [gym] extra.

robots

Built-in (robot, task) pairs, written with the public API above. All are planar (2D). mg.robots.get(name) looks one up by name. Read their source as worked examples.

CallBody plan
mg.robots.walker()Planar biped: torso + 2 x (thigh, shin, foot), 6 motors. Same morphology and 24-dim observation as the legacy walker env, so runs/walker.npz loads.
mg.robots.cheetah()HalfCheetah-like runner: torso + back/front (thigh, shin, foot), 6 motors. 17-dim observation, matches the legacy cheetah env.
mg.robots.hopper()One-legged hopper (MuJoCo Hopper proportions): torso, thigh, leg, foot; 3 motors.
mg.robots.tripod()Horizontal torso on three 2-segment legs (front, middle, back); 6 motors.
mg.robots.worm()5-segment chain lying on the ground that has to crawl forward; 4 motors; 500-step episodes.
robot, task = mg.robots.cheetah()
env = mg.make(robot, task, num_envs=16384)
