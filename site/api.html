Reference

Python API

The whole public surface of import macgym as mg. Robots and tasks are plain Python; everything after mg.make runs on the GPU.

import macgym as mg

Robot

mg.Robot(name: str)

Builder for a planar multibody robot. Bodies are capsules in the x/y plane, connected by hinge joints with a motor at each joint.

robot.body(name, start, end, radius, density=1000)

Adds a capsule. Returns a Body handle.

namestrUnique name, used by s.body(name) and s.contact(name).
start, endtuple[float, float]Endpoints of the capsule axis in metres, at rest pose.
radiusfloatCapsule radius in metres.
densityfloat = 1000kg/m³. Mass and inertia are derived from the shape.

robot.joint(parent, child, at, limits, motor, damping=0.1, stiffness=0.0)

Connects two bodies with a hinge. Returns a Joint handle. Each joint adds one action dimension.

parent, childBodyHandles returned by robot.body.
attuple[float, float]Hinge location in world coordinates at rest pose.
limitstuple[float, float]Joint angle limits in radians.
motorfloatGear: torque in N·m at action = 1. Actions are clipped to [-1, 1].
dampingfloat = 0.1Viscous joint damping.
stiffnessfloat = 0.0Spring back toward the rest angle.

robot.set_root(body)

Selects the body used for s.root, the camera, and distance travelled. Defaults to the first body added.

Task

mg.Task(reward, done=None, episode_steps=1000, obs=None)

What the robot should learn. All callables receive a batched State and return an array of shape (N,).

rewardCallable[[State], mx.array]Per-step reward.
doneCallable[[State], mx.array] | NoneTermination mask. Terminated robots auto-reset.
episode_stepsint = 1000Time limit in control steps.
obsCallable[[State], mx.array] | NoneOverride the automatic observation (root height, angle and velocities, joint q and qd, contacts).

State

The batched view passed to reward, done and obs. Every field is an MLX array with one entry per robot.

FieldShapeMeaning
s.root.x, .y(N,)Root body position. x is relative to the episode start.
s.root.vx, .vy(N,)Root linear velocity, m/s.
s.root.angle, .omega(N,)Root orientation and angular velocity.
s.root.height(N,)Root height above ground.
s.body("name")(N,) eachSame fields as root, for any body: x y vx vy angle omega.
s.joint("name" | i)(N,) each.q angle and .qd velocity.
s.action(N, A)Actions applied this step, in [-1, 1].
s.action_sq(N,)Sum of squared actions. Handy for effort penalties.
s.contact("name")(N,)1 if the body touches the ground, else 0.
s.t, s.dtscalarStep index within the episode, control timestep.

make

mg.make(robot, task, num_envs=4096, seed=0) -> BatchedEnv

Compiles the robot to a Metal kernel and allocates num_envs copies. The returned env exposes reset(), step(actions), render_state() and running metrics, and auto-resets finished episodes.

train

mg.train(env, iters=200, hidden=(256, 256), on_iter=None, save=None) -> TrainResult

Runs PPO on the GPU. Returns TrainResult(policy, history).

itersint = 200PPO iterations (rollout + update).
hiddentuple[int, ...]MLP hidden sizes for actor and critic.
on_iterCallable[[dict], None] | NoneCalled after each iteration with metrics: distance, return, steps/s, elapsed.
savestr | NoneCheckpoint path (.npz) written at the end.

load_policy

mg.load_policy(path, env) -> Policy

Loads a checkpoint. policy.act(obs) returns deterministic actions for a batch of observations.

Policy.export

policy.export(path)

Format is chosen from the extension: .onnx needs onnx, .mlpackage needs coremltools. Install both with pip install -e ".[export]". CoreML export is best effort and raises a clear error if coremltools is missing.

view

mg.view(env, policy=None, port=8765)

Starts the local server and opens the browser viewer for a custom env. With no policy it trains live; with a policy it plays it back.

to_gymnasium

mg.to_gymnasium(env) -> gymnasium.vector.VectorEnv

NumPy in, NumPy out. Use with Stable-Baselines3, CleanRL, or your own trainer. Requires the [gym] extra.

robots

Built-in (robot, task) pairs, written with the public API above. Read their source as worked examples.

CallBody plan
mg.robots.walker()Planar biped: torso, two legs with knees.
mg.robots.cheetah()Planar runner with front and back legs.
mg.robots.hopper()Single leg that has to hop to move.
mg.robots.tripod()Torso with two stiff legs. The quickstart robot.
mg.robots.worm()Chain of segments that moves by undulating.
robot, task = mg.robots.cheetah()
env = mg.make(robot, task, num_envs=16384)
