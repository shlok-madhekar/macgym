Get started

Quickstart

Install MacGym, define a robot, train 4,096 copies of it on your GPU, and export the policy. About five minutes on any Apple Silicon Mac.

Install

MacGym needs an Apple Silicon Mac (M1 or newer) and Python 3.10+. It depends on mlx, numpy and aiohttp.

$ git clone https://github.com/shlok-madhekar/macgym
$ cd macgym
$ pip install -e .

Optional extras:

$ pip install -e ".[gym]"      # gymnasium wrapper
$ pip install -e ".[export]"   # onnx + coremltools

Your first robot

Scaffold a robot file, or write one by hand. A robot is a set of capsule bodies connected by motorized hinge joints. A task is a reward function, an optional termination, and an episode length.

$ macgym new strider
strider.py
import macgym as mg

robot = mg.Robot("strider")   # planar (2D): x forward, y up
torso = robot.body("torso", start=(0, 1.0), end=(0.6, 1.0), radius=0.06)
front = robot.body("front", start=(0.6, 1.0), end=(0.6, 0.5), radius=0.04)
back = robot.body("back", start=(0.0, 1.0), end=(0.0, 0.5), radius=0.04)
robot.joint(torso, front, at=(0.6, 1.0), limits=(-1.0, 1.0), motor=80)
robot.joint(torso, back, at=(0.0, 1.0), limits=(-1.0, 1.0), motor=80)

task = mg.Task(
    reward=lambda s: s.root.vx - 0.001 * s.action_sq,
    done=lambda s: s.root.y < 0.4,
)

if __name__ == "__main__":   # `macgym train strider.py` only reads robot + task
    env = mg.make(robot, task, num_envs=4096)
    result = mg.train(env, iters=200, save="runs/strider.npz")
    print(mg.evaluate(env, result.policy))   # {'dist': ..., 'return': ..., 'survived': ...}

Inside reward and done, s is a batched State: every field is an MLX array with one value per robot. Observations are built from the robot automatically.

Train and watch

$ macgym train strider.py --envs 4096 --iters 200

Each progress line reports mean distance per episode in metres, mean return, simulation throughput, total env-steps and wall time. Real output from a built-in robot on an M3 Pro (lines trimmed):

To watch the whole population learn in your browser, run macgym view. It starts a local server and opens the viewer, where every robot is drawn on one shared runway and the best one is highlighted.

$ macgym view strider.py
PlaygroundPrefer to iterate on the body plan itself? The Playground puts the robot file in an editor next to the live track. Change a leg, press Run, and 4,096 copies start learning.

Export

$ macgym export runs/strider.npz --format coreml   # runs/strider.mlpackage
$ macgym export runs/strider.npz --format onnx     # runs/strider.onnx

Or from Python:

import macgym as mg
from strider import robot, task

env = mg.make(robot, task, num_envs=64)
policy = mg.load_policy("runs/strider.npz", env)
print(mg.evaluate(env, policy))           # mean distance (m), return, fraction still standing
policy.export("strider.onnx")             # or strider.mlpackage; verified against MLX
