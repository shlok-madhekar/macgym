CLI

Five commands: scaffold, train, view, export, benchmark.

Installing the package adds a macgym command. Robot files must define robot and task at module level, or a make_env(num_envs) function. Anywhere a file is accepted you can also pass a built-in name: walker, cheetah, hopper, tripod, worm.

macgym train

$ macgym train <file.py | builtin> [--envs 4096] [--iters 200] [--save PATH]
                [--hidden 256,256] [--seed 0] [--log-every N]

Headless PPO. Prints one progress line per interval: mean distance per episode in metres, mean return, steps per second, total env-steps, elapsed time.

FlagDefaultMeaning
--envs4096Number of robots simulated in parallel.
--iters200PPO iterations.
--saveruns/<name>.npzCheckpoint path.
--hidden256,256MLP hidden sizes, comma-separated.
--seed0Random seed.
--log-everyiters / 20Print a progress line every N iterations.
$ macgym train walker --envs 16384
$ macgym train my_robot.py --iters 400 --save runs/my_robot.npz

macgym view

$ macgym view [<file.py | builtin>] [--port 8765] [--envs 4096] [--no-browser]

Starts the local server and opens the viewer in your browser. A robot file opens in the Playground and starts training; a built-in trains in the viewer; no target lets you pick in the browser. Every robot is drawn on one runway, the best in orange, with a progress chart and replays of earlier generations.

macgym export

$ macgym export <ckpt.npz> [--format onnx | coreml | npz] [--out PATH]

Default format is onnx. Writes <ckpt>.onnx, <ckpt>.mlpackage or <ckpt>_actor.npz next to the checkpoint unless --out is given, then prints the max absolute difference vs the MLX policy. ONNX and CoreML need the [export] extra.

macgym new

$ macgym new <name> [--out PATH] [--force]

Scaffolds <name>.py (name must be a Python identifier) from a template: a planar torso on two legs with feet, 4 motors, and a forward-velocity task, ready for macgym train. Refuses to overwrite without --force.

macgym bench

$ macgym bench [--quick] [--sizes 1024,4096,16384] [--out PATH]

Runs scripts/bench.py: MLX on the GPU vs CPU MuJoCo (one thread, and one process per core). Writes web/bench.json unless --out is given. See Benchmarks.
