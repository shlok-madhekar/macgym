Open-source robot learning for Apple Silicon

Robot learning, on the Mac you already own.

Define a robot in fifteen lines of Python. MacGym compiles it to a Metal kernel, trains 4,096 copies on your Mac's GPU, and exports the policy to CoreML.

tripod.py
import macgym as mg

robot = mg.Robot("tripod")
torso = robot.body("torso", start=(0, 1.0), end=(0.6, 1.0), radius=0.06)
front = robot.body("front", start=(0.6, 1.0), end=(0.6, 0.5), radius=0.04)
back = robot.body("back", start=(0.0, 1.0), end=(0.0, 0.5), radius=0.04)
robot.joint(torso, front, at=(0.6, 1.0), limits=(-1.0, 1.0), motor=80)
robot.joint(torso, back, at=(0.0, 1.0), limits=(-1.0, 1.0), motor=80)

task = mg.Task(
    reward=lambda s: s.root.vx - 0.001 * s.action_sq,
    done=lambda s: s.root.y < 0.4,
)
env = mg.make(robot, task, num_envs=4096)
mg.train(env, iters=200, save="runs/tripod.npz")

01 · DEFINE

Robots are Python

Capsules, hinges, motors, limits. No XML, no URDF. A Robot is a few method calls you can read in one screen.

02 · COMPILE

One GPU thread per robot

Each body plan becomes its own Metal kernel. Thousands of copies step in parallel with no Python loop over environments.

Rollouts, advantages and updates run in MLX. Sim state and network weights share one pool of unified memory.
