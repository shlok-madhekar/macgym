New to robot learning?

It learns the way you learned to ride a bike: by trying.

  1. Build a body. Sticks joined by motors. No physics degree needed: each part is one line of Python.
  2. Say what "good" means. For walking, that is "move forward without falling over".
  3. Press Run. Thousands of copies flail, the ones that get further teach the rest, and in about a minute they walk.

Want the details?

Batched planar rigid-body sim + PPO, on one chip.

Physics
2D capsule bodies, motorized hinges, joint limits, contact with friction. Each body plan compiles to its own Metal kernel, one GPU thread per robot.
Learning
PPO in MLX. Sim state and network weights share unified memory, so nothing is copied between simulator and learner.
Throughput
3.0M env-steps/s, 4,096 walkers (sim only) · 272K steps/s end to end with PPO updates · Apple M3 Pro.
vs MuJoCo
~21x the env-steps/s of MuJoCo on all 11 CPU cores of the same laptop, on a quiet run. Different physics (2D impulse vs 3D constraint solver), so read it as RL experience per second, not identical sims.
Export
CoreML and ONNX, checked against the trained network: max error 3.6e-7 / 4.8e-7.
Interop
mg.to_gymnasium(env) for your own trainer. CLI: new · train · view · export · bench.
Limits
Planar (2D) only. No sim-to-real transfer yet; next step is a sim-to-sim test in MuJoCo.

strider.py
import macgym as mg

robot = mg.Robot("strider")   # planar (2D): x forward, y up
torso = robot.body("torso", start=(0, 1.0), end=(0.6, 1.0), radius=0.06)
front = robot.body("front", start=(0.6, 1.0), end=(0.6, 0.5), radius=0.04)
back = robot.body("back", start=(0.0, 1.0), end=(0.0, 0.5), radius=0.04)
robot.joint(torso, front, at=(0.6, 1.0), limits=(-1.0, 1.0), motor=80)
robot.joint(torso, back, at=(0.0, 1.0), limits=(-1.0, 1.0), motor=80)

task = mg.Task(
    reward=lambda s: s.root.vx - 0.001 * s.action_sq,
    done=lambda s: s.root.y < 0.4,
)

if __name__ == "__main__":   # `macgym train strider.py` only reads robot + task
    env = mg.make(robot, task, num_envs=4096)
    result = mg.train(env, iters=200, save="runs/strider.npz")
    print(mg.evaluate(env, result.policy))   # {'dist': ..., 'return': ..., 'survived': ...}
